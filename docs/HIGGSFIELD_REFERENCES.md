## UI reference sheet

https://d8j0ntlcm91z4.cloudfront.net/user_3IgyPK9KRpa0YtpAdolGkHQafSY/hf_20260831_222907_3854a83b-6fce-4302-8a6b-8783f64c0f90.png

Prompt focus: compact tactical HUD, reload indicator, armor impact-angle readout, ammunition status and internal X-ray component panel.

These images are references for art direction. The initial runtime deliberately uses procedural low-poly meshes and immediate-mode UI so the combat prototype remains lightweight on low-spec machines. They can be replaced by production art later without changing the combat architecture.
